# Web3 学习路线图网站 - 需求分析与产品规划

## 1. 核心理念与目标
打造一个寓教于乐的 Web3 学习平台，通过游戏化机制（Gamification）降低 Web3 概念的认知门槛。用户不仅仅是阅读文档，而是在"升级打怪"的过程中掌握去中心化、区块链基础、钱包使用、智能合约等核心技能。

## 2. 核心功能模块

### 2.1 学习导航路径 (User Journey Map)
- **可视化地图**：摒弃传统的列表式目录，采用类似 RPG 游戏的地图（World Map）形式。
    - **新手村 (Web3 Basics)**：甚至从 "创建一个钱包" 开始。
    - **矿工森林 (Blockchain Fundamentals)**：理解 PoW, PoS。
    - **交易集市 (DeFi & Tokens)**：理解 Token, Swap, Liquidity。
    - **合约高塔 (Smart Contracts)**：Solidity 基础。
    - **NFT 画廊 (NFT & Metaverse)**。
- **解锁机制**：前置关卡（知识点）通过后，才能解锁后续地图区域。

### 2.2 学习资料与小游戏 (Game-Based Learning Materials)
- **互动式教学**：
    - **概念解析**：简短的图文/视频介绍。
    - **小游戏验证 (Mini-games)**：
        - *钱包连接挑战*：模拟连接钱包并签名，做对了才能进入下一步。
        - *哈希碰撞小游戏*：通过调整 nonce 找到特定开头的哈希值，理解挖矿原理。
        - *私钥助记词拼图*：打乱的助记词排序，强化安全记忆。
        - *Gas 费计算器*：在限时内根据网络拥堵情况选择合适的 Gas 费打包交易。
- **实战演练**：
    - 在测试网（Testnet）上发一笔真实的交易。
    - 铸造（Mint）一个专属的 NFT 勋章。

### 2.3 角色成长系统 (RPG Elements)
- **角色属性**：
    - **XP (经验值)**：完成课程获得。
    - **Level (等级)**：Web3小白 -> 链上探索者 -> 智能合约学徒 -> DeFi 巨鲸。
- **装备/战利品 (On-chain Reputation)**：
    - 每通过一个大章节，获得一个 **SBT (Soulbound Token)** 或 NFT 徽章。
    - **排行榜**：展示学习进度最快的用户。

## 3. 技术架构建议 (MVP)

- **前端框架**：`Next.js` (React) - Web3 首选框架，SEO 友好。
- **UI 组件库**：Tailwind CSS + Framer Motion (用于动画效果) + Shadcn/ui。
- **Web3 集成**：`RainbowKit` + `Wagmi` + `Viem` (连接钱包，交互合约)。
- **游戏引擎**：
    - 简单交互：Web DOM 动画。
    - 复杂交互（可选）：`Phaser.js` 或 `React-Three-Fiber` (3D 场景)。
- **后端/数据库**：
    - 用户进度存储：`Supabase` (PostgreSQL) 或 `Firebase`。
    - 链上数据索引：可选 `The Graph`。

## 4. 下一步实施计划
1. **原型设计**：绘制学习地图草图，确定第一章"新手村"的包含内容。
2. **技术选型**：初始化 Next.js 项目，配置 Tailwind 和 Web3 钱包连接。
3. **开发 MVP**：实现"连接钱包"任务和"第一个知识点"的通关流程。
