# Web3 学习路线图 - 多语言支持实施计划

## 目标
为系统添加英文和中文的多语言支持，从单一语言升级为国际化架构。

## 技术选型
- **库**: `next-intl` (Next.js App Router 的最佳实践)
- **路由策略**: 基于路径的路由 (e.g., `/en/level/1`, `/zh/level/1`)
- **默认语言**: `en`

## 拟议变更

### 1. 依赖与配置
- [NEW] 安装 `next-intl`。
- [NEW] 创建 `messages/en.json` 和 `messages/zh.json` 存放翻译键值对。
- [NEW] 创建 `src/i18n/request.ts` 配置请求上下文。
- [NEW] 创建 `src/middleware.ts` 处理语言路由重定向。
- [MODIFY] `next.config.ts` 集成 `createNextIntlPlugin`.

### 2. 目录结构重构 (Critical)
将 `src/app` 下的页面文件移动到 `src/app/[locale]` 动态路由文件夹。
- `src/app/page.tsx` -> `src/app/[locale]/page.tsx`
- `src/app/layout.tsx` -> `src/app/[locale]/layout.tsx`
- `src/app/level/[id]/page.tsx` -> `src/app/[locale]/level/[id]/page.tsx`

### 3. 组件重构
- [MODIFY] `LearningMap`, `GameLayout`, `WalletConnectGame`:
    - 移除硬编码文本。
    - 使用 `useTranslations()` 获取文本。
- [NEW] `LanguageSwitcher`: 语言切换组件 (Dropdown 或 Toggle)。

### 4. 翻译内容规划
- **Homepage**: 标题, 副标题, 连接钱包按钮文本。
- **Game/Map**: 关卡名称 (Beginner Village -> 新手村), 任务描述。
- **System**: 加载状态, 错误提示.

## 验证计划
- 访问 `/` -> 自动重定向到 `/en` (或浏览器默认语言)。
- 访问 `/zh` -> 显示中文界面。
- 切换语言 -> 路由变化且内容更新。
