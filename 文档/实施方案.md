# Web3 学习路线图网站 - 实施计划

## 目标描述
构建一个基于 Next.js 的 Web3 学习平台，通过游戏化路径（Learning Path）和互动小游戏帮助用户学习 Web3 知识。

## 用户审查要求
- [ ] 确认"游戏化"的具体程度（是简单的进度解锁，还是包含复杂动画的角色扮演）。
- [ ] 确认首个 MVP 版本的范围（例如：仅包含"连接钱包"和"发送交易"两个关卡）。

## 拟议变更

### 架构与初始化
- [NEW] 初始化 Next.js 项目 (Tailwind CSS, TypeScript)。
- [NEW] 配置 Web3 依赖 (`wagmi`, `viem`, `@rainbow-me/rainbowkit`)。
- [NEW] 建立目录结构：
    - `components/`: UI 组件 & 游戏组件
    - `app/`: 页面路由
    - `lib/`: 工具函数 & 合约交互逻辑
    - `store/`: 状态管理 (Zustand) - 用于管理用户 XP、等级、解锁进度。

### 核心功能模块

#### 1. 学习地图 (LearningMap)
- **实现方案**：使用 SVG 或 Canvas 绘制路径节点。
- **状态**：
    - `Locked`: 灰色，不可点击。
    - `Active`: 高亮，当前关卡。
    - `Completed`: 金色/打钩，已完成。

#### 2. 小游戏引擎 (MiniGameEngine)
- **架构**：一个通用的 `GameLayout` 组件，嵌入具体的游戏逻辑。
- **示例游戏**：
    - `WalletConnectGame`: 检测用户是否连接钱包。
    - `GasEstimator`: 简单的数值选择题。

#### 3. 用户进度系统 (UserProgress)
- **本地存储**：MVP 阶段使用 `localStorage` 存储解锁进度和 XP。
- **链上存储 (可选)**：后续可生成 SBT 徽章。

## 验证计划

### 自动化测试
- 运行 `npm run dev` 启动开发服务器。
- 只有基础的单元测试，主要依赖人工验证。

### 手动验证
1. **连接钱包**：点击连接按钮，确认能调起 MetaMask/Rabby。
2. **解锁流程**：完成第一关后，确认第二关的状态从 Locked 变为 Active。
3. **游戏交互**：在"Gas 计算"游戏中选择错误答案，确认有错误提示；选择正确答案，确认获得 XP。
