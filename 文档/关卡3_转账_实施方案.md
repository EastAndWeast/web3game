# Web3 学习路线图 - 关卡 3 (转账) 实施计划

## 目标
实现 "First Scroll" (初级卷轴) 关卡，教用户如何发送第一笔链上交易 (Transfer ETH)。

## 交互设计
1. **任务目标**: 向指定地址发送少量 ETH。
2. **操作流程**:
   - 用户进入关卡。
   - 显示任务要求：发送 0.0001 ETH 到 "Master's Address" (预设地址)。
   - 提供转账表单：
     - 目标地址 (只读/可复制)。
     - 金额输入框 (或者固定金额)。
     - "Sign & Send" 按钮。
   - 唤起钱包签名。
   - 等待交易上链确认。
   - 成功后显示交易哈希 (Tx Hash)，关卡完成。

## 技术方案
1. **Hooks**: 使用 `wagmi` 的 `useSendTransaction` 和 `useWaitForTransactionReceipt`。
2. **验证**: 
   - 监听 `isSuccess` 状态。
   - 简单起见，不强制验证链上状态，只要本地交易回执成功即视为通过。
